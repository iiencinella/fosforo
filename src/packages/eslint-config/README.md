# `@repo/eslint-config`

Configuraciónes ESLint compartidas para el monorepo `fosforo`.

## Exports

- `@repo/eslint-config/base`
- `@repo/eslint-config/next-js`
- `@repo/eslint-config/react-internal`

## Uso

Este paquete centraliza reglas reutilizables para evitar configuraciónes duplicadas entre workspaces de `src/apps/`, `src/mobile/`, `src/desktop/` y `src/packages/`.
