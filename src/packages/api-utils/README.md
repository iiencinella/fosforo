# `@repo/api-utils`

Utilidades compartidas para endpoints y respuestas HTTP del ecosistema.

## Incluye

- `safeHandler` para encapsular errores de handlers.
- `jsonOk` para respuestas exitosas.
- `jsonError` para respuestas de error.
- `parseJsonBody` para parseo seguro de payloads JSON.

## Uso

Este paquete sirve como base ligera para estandarizar endpoints en workspaces web o utilidades backend sin repetir helpers de respuesta.
