# `@repo/typescript-config`

Configuraciónes TypeScript reutilizables para los workspaces del monorepo `fosforo`.

## Exports

- `@repo/typescript-config/base.json`
- `@repo/typescript-config/nextjs.json`
- `@repo/typescript-config/react-library.json`

## Uso

Este paquete centraliza presets de TypeScript para evitar divergencias entre apps y paquetes compartidos.

## Objetivo

Mantener reglas de compilación y tipado consistentes entre `src/apps/`, `src/mobile/`, `src/desktop/` y `src/packages/`.
