# Portal (Astro)

Aplicación web `0101 Portal` del ecosistema Fósforo.

## Comandos

- `pnpm dev --filter=portal`
- `pnpm build --filter=portal`
- `pnpm check-types --filter=portal`

## Alcance MVP

- Catálogo inicial de aplicaciónes.
- Novedades manuales en `src/content/novedades`.
- Formularios públicos para contacto y feedback.
- Sección de desarrolladores con derivación de contribuciones por pull request.
