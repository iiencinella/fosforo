## Enfoque

Esta carpeta concentra la arquitectura común del ecosistema, la estructura de Turborepo y la arquitectura especifica de cada plataforma soportada.

La vision rectora actual debe entender a Fósforo como una plataforma por capas con multiples clientes, donde frontend, servicios de aplicación, core systems e infraestructura evolucionan como partes coordinadas de un mismo sistema.
