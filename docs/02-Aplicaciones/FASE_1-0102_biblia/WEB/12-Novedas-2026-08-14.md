# Novedas - 2026-08-14

## Página de compartir con redes sociales

Se mejoró la página `/compartir` para incluir botones de redes sociales, copiar enlace, Web Share API nativa y vista previa de OG card. La página ahora acepta el query param `?date=YYYY-MM-DD` para seleccionar la fecha de la jornada a compartir.

### Cambios realizados

- **`src/apps/biblia/src/pages/compartir.astro`**: reescritura completa del section de compartir con:
  - Botones de Facebook, X/Twitter, LinkedIn y WhatsApp con URLs construidas dinámicamente (`encodeURIComponent`).
  - Botón de copiar enlace (`navigator.clipboard` con fallback a `document.execCommand`).
  - Botón de Web Share API nativa (`navigator.share`) que se oculta si no está disponible.
  - Vista previa del enlace con imagen OG, título y descripción.
  - Soporte de fecha por query param (`?date=YYYY-MM-DD`) para resolver la jornada litúrgica correspondiente.
- **`src/apps/biblia/src/components/Head.astro`**: OG image cambiada a `og-biblia.png`. Meta tags OG mejorados con `og:image:type`, `og:image:width` (1200), `og:image:height` (630) e `og:locale` (`es_ES`).
- **`src/packages/ui/src/portal-bible-hub.tsx`**: los botones de compartir en modales de búsqueda y liturgia ahora incluyen `?ref=` y `?date=` como query params en la URL de `/compartir` para preservar el contexto de la jornada.
- **`src/packages/ui/src/share-button.tsx`**: simplificación del método `getUrl` de LinkedIn (no requiere `title`).
- **`src/apps/biblia/src/styles/gospel-widget.css`**: cambio de import de `shared-styles.css` a `@repo/ui/foundation.css`.
- **`src/apps/biblia/package.json`**: añadida dependencia `sharp` para generación de imagen OG.

## Imagen OG con script de generación

Se creó un script para generar la imagen OG (`og-biblia.png`) de forma automatizada.

- **`src/apps/biblia/scripts/generate-og-png.mjs`**: script que genera un PNG de 1200x630 con `sharp` para usar como `og:image` en meta tags.
- **`src/apps/biblia/public/og-biblia.png`**: imagen OG generada.
