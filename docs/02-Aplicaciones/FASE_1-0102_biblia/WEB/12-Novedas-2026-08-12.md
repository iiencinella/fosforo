# Novedas - 2026-08-12

## Nueva feature: Widget embebible del Evangelio del día

Se creó un widget web embebible vía iframe que muestra el evangelio del día según el calendario litúrgico católico (Rito Romano Argentina). El widget es autónomo, con estilos inline y soporte para tema claro/oscuro.

### Archivos creados

- `src/apps/biblia/src/components/GospelWidget.tsx` — Componente React del widget con lógica de normalización de URLs de YouTube y Spotify.
- `src/apps/biblia/src/styles/gospel-widget.css` — Estilos scoped al widget usando tokens del ecosistema.
- `src/apps/biblia/src/pages/widget/gospel.astro` — Página Astro embebible que resuelve el evangelio server-side.

### Parámetros del widget

| Parámetro | Requerido | Descripción                                  |
| --------- | --------- | -------------------------------------------- |
| `theme`   | No        | `light` o `dark` (default: `dark`)           |
| `date`    | No        | Fecha en formato `YYYY-MM-DD` (default: hoy) |
| `youtube` | No        | URL completa de video de YouTube             |
| `spotify` | No        | URL completa de episodio/canción de Spotify  |

### Snippet de embebido

```html
<!-- Solo evangelio -->
<iframe
  src="https://biblia.fosforo.org/widget/gospel?theme=light"
  width="420"
  height="340"
  frameborder="0"
  style="border-radius: 12px;"
  title="Evangelio del día"
></iframe>

<!-- Evangelio + YouTube + Spotify -->
<iframe
  src="https://biblia.fosforo.org/widget/gospel?theme=light&youtube=https://www.youtube.com/watch?v=XXXXX&spotify=https://creators.spotify.com/pod/profile/radio-corazn-paran/episodes/SLUG-e3n9qra/a-acqn6tm"
  width="420"
  height="780"
  frameborder="0"
  style="border-radius: 12px;"
  title="Evangelio del día"
></iframe>
```

### Normalización de URLs

El componente `GospelWidget` incluye funciones de normalización para:

- **YouTube**: acepta `youtube.com/watch?v=ID` y `youtu.be/ID`
- **Spotify**: acepta `open.spotify.com/episode/ID`, `open.spotify.com/track/ID`, `creators.spotify.com/.../episodes/SLUG/...` y `podcasters.spotify.com/.../episodes/SLUG/...`

Las funciones extraen el ID del contenido y construyen el embed URL correspondiente (`youtube.com/embed/ID` y `open.spotify.com/embed/type/ID`).

## Lecturas litúrgicas anuales desde EWTN

Los scripts en `src/apps/biblia/src/scripts/` extraen las lecturas bíblicas diarias de [EWTN Daily Readings](https://www.ewtn.com/daily-readings) y generan SQL para actualizar la tabla `liturgy_daily_readings` en Supabase.

### Scripts disponibles

| Script               | Descripción                                                 |
| -------------------- | ----------------------------------------------------------- |
| `fetch-ewtn-curl.ts` | Extrae lecturas completas de un año (Ene-Dic)               |
| `fetch-ewtn-rest.ts` | Extrae lecturas desde una fecha intermedia hasta fin de año |
| `test-fetch.ts`      | Prueba rápida con 3 fechas para verificar parsing           |

### Cómo ejecutar

**1. Extraer lecturas de un año completo:**

```bash
# Desde la raíz del monorepo
npx tsx src/apps/biblia/src/scripts/fetch-ewtn-curl.ts
```

El script genera:

- `src/apps/biblia/src/scripts/YYYY-readings.sql` — UPDATE statements para Supabase
- `src/apps/biblia/src/scripts/YYYY-readings.json` — Datos en formato JSON

**2. Ejecutar el SQL en Supabase:**

Copiar el contenido del archivo `.sql` y ejecutarlo en el SQL Editor de Supabase, o ejecutarlo por batches desde el agente.

**3. Para años futuros (cuando EWTN publique los datos):**

```bash
# Cambiar YEAR en el script o crear copia para el año deseado
npx tsx src/apps/biblia/src/scripts/fetch-ewtn-curl.ts
```

### Notas importantes

- **EWTN publica lecturas con anticipación limitada** (~2-3 meses). Para fechas futuras lejanas, el script devolverá 0 resultados. Ejecutar periódicamente conforme se publiquen.
- **Rate limiting**: El script usa `curl` con delay de 1.5s entre peticiones para evitar bloqueos. Un año completo tarda ~10-15 minutos.
- **Ciclo litúrgico**: Los registros en `liturgy_daily_readings` deben crearse primero con el ciclo correcto (A, B o C) usando los datos de `liturgy_day_profiles`.
- **Traducción**: Los nombres de libros bíblicos se traducen automáticamente de inglés a español.

### Ejemplo: generar lecturas para 2027

```bash
# 1. Crear registros base (ejecutar en Supabase SQL Editor)
INSERT INTO liturgy_daily_readings (reading_date, rite, region_code, celebration_type, celebration_name, cycle, week, source_year)
SELECT ('2027-' || month_day_key)::date, 'roman', 'AR', rank_slug, COALESCE(title_2026, celebration_name), 'A', week, 2027
FROM liturgy_day_profiles WHERE rite = 'roman' AND region_code = 'AR';

# 2. Ejecutar script de extracción (cuando EWTN publique los datos)
npx tsx src/apps/biblia/src/scripts/fetch-ewtn-curl.ts

# 3. Ejecutar el SQL generado en Supabase
```
