# License response templates (English)

This document provides short, reusable responses for license-related questions in issues and pull requests.

## 1) General usage question

Thanks for asking. This repository uses a dual licensing model:

- Code and scripts: PolyForm Noncommercial 1.0.0
- Textual and multimedia content: CC BY-NC 4.0

Important: when describing the code publicly, the correct terminology is `source-available`, community-oriented, and non-commercial. It should not be presented as OSI Open Source because commercial use is restricted by default.

In both cases, commercial use is not allowed by default. If your scenario involves monetary compensation or commercial advantage, we need to evaluate it as a separate written permission/commercial license.

## 2) Apparently non-commercial use

Based on your description, this appears to be a non-commercial use. You may proceed as long as you keep attribution and required notices according to the applicable license.

Reference: `LICENSE`, `NOTICE`, and `ATTRIBUTIONS.md`.

## 3) Commercial or monetized use

Thanks for the details. Since this includes a commercial/monetization component, it is outside the default permissions for this repository.

If you are interested, we can evaluate a separate written authorization or commercial license. Please share scope, distribution channel, and revenue model.

## 4) Question about what counts as "commercial"

In general terms, "commercial" includes uses primarily intended for commercial advantage or monetary compensation (direct or indirect).

If your case is borderline, open an issue including:

- the material you plan to use,
- usage context,
- whether there is monetary benefit,
- how attribution/notices will be preserved.

We can then provide case-by-case guidance.

## 5) Polite close when authorization is not possible

Thanks for your interest in Fósforo. At this time, we cannot authorize that commercial use under the proposed terms.

If you want, we can explore non-commercial alternatives or a different, narrower proposal.

## 6) PR reminder

Thanks for your contribution. Before merge, please confirm:

- all added material is compatible with `LICENSE`,
- no assets with conflicting terms were included,
- required attribution and notices are preserved.
- `ATTRIBUTIONS.md` was updated using the mandatory attribution template if you added new, adapted, or imported content.
