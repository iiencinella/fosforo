# Legal y Licencias - Ecosistema Fósforo

## Licencias del repositorio

- **Codigo fuente y scripts:** PolyForm Noncommercial 1.0.0
- **Contenido textual y multimedia:** CC BY-NC 4.0

La descripción publica correcta del codigo del repositorio es `source-available`, comunitario y no comercial. No debe presentarse como Open Source en sentido OSI mientras la licencia vigente restrinja el uso comercial.

Ver `LICENSE`, `NOTICE`, `AUTHORS`, `ATTRIBUTIONS.md` en la raiz del repositorio.

## Para contribuidores

- Ver `CONTRIBUTING.md` para el flujo de trabajo y aceptación de licencias.
- Todo contenido textual o multimedia nuevo, adaptado o importado debe registrarse en `ATTRIBUTIONS.md` usando la plantilla obligatoria de atribución antes del merge.
- Para dudas, abre un issue usando la plantilla `license-question.yml`.
